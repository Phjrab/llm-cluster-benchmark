Python3.12 with numpy, matplotlib, reportlab. Rendering: pdftoppm/pdfinfo (Poppler).
Gmsh PythonAPI4.13.1 and matching libgmsh.so.4.13.1 (official PyPI gmsh4.13.1 package).
CalculiX2.20 / SPOOLES2.2: official Debian packages, extracted locally, no system settings changed.
https://deb.debian.org/debian/pool/main/c/calculix-ccx/calculix-ccx_2.20-1_amd64.deb
https://deb.debian.org/debian/pool/main/s/spooles/libspooles2.2_2.2-14_amd64.deb

Dependency layout expected under STUDY_DEPS:
python/gmsh.py and matching dynamic library accessible to runtime
ccx/usr/bin/ccx
ccx/usr/lib/x86_64-linux-gnu/libspooles.so.2.2

Example dependency preparation in a user-chosen local folder:
python -m pip install --target tools/python gmsh==4.13.1
mkdir -p tools/ccx
# Download the two official Debian package URLs above to calculix.deb and spooles.deb
dpkg-deb -x calculix.deb tools/ccx
dpkg-deb -x spooles.deb tools/ccx

Run from this study folder (STUDY_DEPS defaults to ../jetson-pla-study/tools when reusing the existing workspace pipeline):
STUDY_DEPS=/absolute/path/to/tools python run_study.py
STUDY_DEPS=/absolute/path/to/tools python verify_solver.py
python postprocess.py
python check_mesh.py
STUDY_DEPS=/absolute/path/to/tools python plot_results.py
python build_report.py

All original source STEP hashes and actual generated output identities are recorded. NPZ convenience intermediates are regenerated by run_study.py and postprocess.py; original MSH/INP/FRD/DAT and solver logs are retained in the canonical archive. Frame/pin source files are local ./frame.step and ./pin.step, without fallback to historical v2 geometry. Solver binaries and vendor documentation are not archived.
