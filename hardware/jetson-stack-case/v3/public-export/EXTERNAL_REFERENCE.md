# External NVIDIA reference

The public FCStd, fabrication STEP/STL, and own-frame seating-contact surfaces contain the assistant-authored enclosure geometry only. The NVIDIA developer-kit/stock-guard CAD is excluded from these native/source/fabrication files because redistribution terms for the official STEP model were not established.

The private validation source and private guard contact-face inputs are not part of the public package. CAD render previews use the official reference only to illustrate clearance and preserve the stock guard/antennas; they are not fabrication geometry or FreeCAD GUI screenshots.

Official source:
https://developer.nvidia.com/downloads/assets/embedded/secure/jetson/orin_nano/docs/jetson_orin_nano_devkit_3d_step_model.zip/

The public Parameters sheet and owned native Part/Fillet/Chamfer/Boolean/Link feature history are preserved. It can be edited without the NVIDIA geometry, but any changes affecting fit require revalidation against the actual kit or an authorized reference model.
